# Own-answer reference message

The user message of the own-answer reference read. It is a gut read that puts the juror's own answer to the same question where a reference would go, without calling it expert or ground truth. `{own}` is the juror's answer from self-solve. It was read for every answer to a question the juror had answered.

```text
CONVERSATION:

{convo}

REFERENCE ANSWER for the final question:
{own}

Grade the FINAL assistant response. End with VERDICT: CORRECT or VERDICT: INCORRECT.
```
