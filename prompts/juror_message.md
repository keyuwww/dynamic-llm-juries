# Juror message

The user message of every gut read and reasoned read, in the screening check, the main reads, the repeat reads and the safeguard juror's reads. It carries no reference answer. `{convo}` is each turn of the conversation as `[USER]` or `[ASSISTANT]` and its text, separated by blank lines.

```text
CONVERSATION:

{convo}

Grade the FINAL assistant response. End with VERDICT: CORRECT or VERDICT: INCORRECT.
```
