Frozen Cascade

A cheap judge (Jev, Laya, or jeff) is trusted when it's confident; when it isn't, the item is escalated to a stronger reasoning judge (gpt-oss-120b). The confidence threshold is tuned on one half of the data and frozen before touching the other half — so these numbers are not the best point a sweep could find after the fact.

Reproducing arXiv:2609.26550, “JEV-as-a-Judge: Accept When Confident, Escalate When Unsure.” Built on judge output already collected — no new API calls for this analysis.

How the frozen threshold works

  1. Split items in half: a tune set and a test set.
  2. On tune only, sweep τ and keep whichever value maximizes cascade agreement with the human label.
  3. Freeze that τ. Apply it, unchanged, to test: if confidence ≥ τ, use the cheap judge's own verdict; otherwise discard it and use gpt-oss-120b's verdict instead.
  4. Report cascade accuracy on test, as a share of gpt-oss-120b's own standalone accuracy on the same test items.
gpt-oss-120b is the strongest model available in this project's judge pool, but it's smaller than the frontier comparator the original paper used — so "100% retained" here is relative to a lower ceiling than the paper's own claim.
