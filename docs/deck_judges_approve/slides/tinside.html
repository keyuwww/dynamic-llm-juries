About 1.25 minutes. Each box is an arrow in the model’s hidden state: correctness = truly right minus truly wrong answers; belief = wrong answers it believes minus wrong answers it never reaches. Columns are the role: solving (the answer placed in the model’s own voice, read after “FINAL:”) and judging (read after “VERDICT:”). Numbers are cosines: 1 = same direction, 0 = unrelated. A vs B: the judge’s sense of correct is unrelated to the solver’s (settled, Qwen-9B and Qwen-35B). B vs D: while grading, believing a wrong answer looks like it being right (0.49 to 0.80), more than while solving (0.26 to 0.54), which fits the approvals. Caveat: partly the lean toward saying CORRECT (Qwen-35B on BFF drops 0.72 to 0.23 once removed); Qwen only. Full deck: 3.1 to 3.4.
