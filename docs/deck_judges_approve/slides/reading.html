Current reading

A JUDGE MOSTLY ASKS

“Does this match what I get?”

It re-derives the answer, out loud when thinking, silently when not. Belief predicts where that lands, so it predicts the verdict.

LOW BELIEF

Errors come from the grading frame. Committing its own answer first removes them: +5 balanced accuracy.

HIGH BELIEF

Errors are shared across families (~80%). Prompts and a second juror don’t fix them; an expert reference does (62 → 12%, BFF).

For a jury: confidently wrong items need a reference outside these models (an expert answer, a much stronger model, a tool or a calculation), not another juror of similar strength. On BFF an expert reference answer confirms this: strong-belief wrong approvals fall from 62 to 12 percent (REPORT.md Experiment 10). A stronger model as the reference is not yet tested.
