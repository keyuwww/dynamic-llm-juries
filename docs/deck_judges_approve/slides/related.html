WHAT WE ADD

No authorship. The judge never wrote any candidate.

Belief per answer. Measured by re-solving, not one sample.

Inside the model. Hidden states and transcripts show the mechanism.

Our setup directly tests Roytburg's alternative: if the judge favours answers it would give itself, whoever wrote them, then "self-preference" is largely belief. Goel's effect is the model-level version of ours; we measure it per answer. Prior work on what happens inside the model is on the next slide.
