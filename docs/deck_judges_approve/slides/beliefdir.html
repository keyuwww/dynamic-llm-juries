4.6 · INSIDE THE MODEL

Does belief look like correctness inside?

TWO DIRECTIONS IN THE SAME ROLE

Correctness: right answers minus wrong answers.

Belief: wrong answers the model believes minus wrong answers it never reaches.

Then the cosine between them.

WHY

If they point the same way at the verdict, believing a wrong answer looks like it being right.

WHERE BELIEF COMES FROM

BFF: the 7 solo tries (believed ≥ 4/7). BBEH: 5 solo tries (believed ≥ half).

Only wrong answers enter the belief direction, so it cannot simply be correctness again. RB2 Math has only about 9 believed wrong answers per model, too few, so it is not used.
