2.3 · BELIEF · DATA CHECK

First, fix the labels

THE PROBLEM

Some RB2 Math answers marked “wrong” reach the right value, written differently.

9 L vs 9.02 L

476,000,000 vs 476,252,000 eV

A judge that “believes” these is just right, so they inflate the top belief group.

HOW

GLM-5.3-Flash compared every wrong answer’s final value with each right answer to the same question: 549 pairs, $0.52.

RESULT

61 mislabelled answers (180 rows) removed. The main effect got slightly stronger: +52 → +54.

Not audited this way: BFF and JudgeBench labels (free-form or pairwise; need hand checks).

The mislabelled answers were concentrated among answers the judges believe 7/7, so removing them more than halved that group on RB2 Math (now 10 answers). One earlier probe result (confident-belief probe on RB2 Math) turned out to be this artefact and was dropped.
