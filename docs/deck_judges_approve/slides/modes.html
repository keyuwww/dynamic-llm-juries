A.6 · APPENDIX · THINKING ON, OFF, NO GENERATION

Three settings: how much the judge writes first

SettingWhat the judge writes before “VERDICT:”Used in
Thinking onA long hidden reasoning trace, then its answerTranscripts (blue bars)
Thinking offNo thinking block, but still a short written explanation: “The steps look correct… VERDICT: CORRECT”Main belief result, transcripts (grey bars), the fixes
No generationNothing at all: we place the answer, add “VERDICT:” ourselves, and read the model’s state right thereInside the model (four arrows)

THINKING OFF ≠ SILENT

It still writes a short explanation; it just doesn’t think at length.

NO GENERATION = SNAP JUDGMENT

The judge’s state before it has written or thought anything.

THE SAME MOMENT, IN BEHAVIOUR

The verdict read before any explanation already shows +35 points of belief effect (+54 at the final verdict).

Use if someone asks what "thinking off" means, or why the inside-the-model result needs no generated text. The inside-the-model states were never captured after a thinking-on trace, so whether the belief-correctness overlap changes with long reasoning is untested.
