Benchmarks, and why each one

BenchmarkWhat the judge seesWhy we use it
RB2 MathA math question + one answer (RewardBench 2)Short final answer: easy to match
JudgeBenchA question + two answers, pick the right oneLetter answers: matched exactly
BFF-BenchA finance conversation + one answerLabels from unanimous human experts
BBEHHard reasoning puzzles + one answerInside-the-model work; mostly beyond the judges

EVERY ITEM

A question · a candidate answer written by another model · a right/wrong label. The judge grades it. About 2,300 wrong candidates per judge on the main set (RB2 Math + JudgeBench + BFF).

JudgeBench coding pairs are dropped because they have no short final answer to compare. BBEH is not in the main set because the judges rarely solve it, so belief is mostly zero there.
