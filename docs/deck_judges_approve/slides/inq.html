3.1 · INSIDE THE MODEL · QUESTION AND METHOD

Inside the judge, does “I’d say this” look like “this is right”?

WHY ASK

Judges approve wrong answers they believe (§2).

If, while grading, a believed answer looks like a right answer inside the model, that would explain the approvals.

TWO ARROWS IN THE MODEL’S HIDDEN STATE

Correctness: truly right answers minus truly wrong ones (benchmark label).

Belief: wrong answers it believes (≥ 4/7) minus wrong answers it never reaches (0/7).

Compare them with a cosine: 1 = same direction, 0 = unrelated.

THE TEST

Measure that cosine in two roles: judging the answer, and solving (the same answer in its own voice). If belief drives approval, the arrows should line up more when judging.

An arrow is a difference of means: the average hidden state of one group of answers minus the other's, with each question's average removed first so question difficulty can't leak in.
