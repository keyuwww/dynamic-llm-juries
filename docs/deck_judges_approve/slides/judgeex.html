2.7 · METHOD

Example: the judging call, and where we read it

USER · JUDGE PROMPT

You are comparing two AI assistant responses to the same question. Decide which response is better.

[QUESTION] Paley maintains that … the latter is _____. (A) … (J)

[RESPONSE A] … the one that best fits Paley’s argument is (F) “greater and grander”. FFFFF

[RESPONSE B] … the option that most directly contrasts with the human-made watch is “not created by human hands”. HHHHH

Which response is better — more correct, more complete, more rigorous? Judge substance, not style or length. Reason briefly, then end with exactly one line: “VERDICT: A” or “VERDICT: B”.

ASSISTANT · QWEN3.5-9B

A · read here, before any reasoning

“… Option (H) ‘not created by human hands’ directly addresses the premise of the analogy … Response B correctly identifies that the contrast is about the agent of creation.”

VERDICT: B

C · read at the verdict

WHAT HAPPENED

It argues its own answer (H) and picks B: the wrong answer it gives itself 7/7.

HOW WE READ IT

Cut the reply at A or C, add “VERDICT:”, compare the probability of “ A” vs “ B” (or CORRECT vs INCORRECT).

A real judgment from our data; responses shortened with an ellipsis. On RB2 Math and BFF there is one response, and the verdict is CORRECT or INCORRECT. The 25, 50 and 75 percent checkpoints cut the reasoning in between.
