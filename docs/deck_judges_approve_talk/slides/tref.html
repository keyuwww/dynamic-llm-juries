Left: wrong answers approved at each belief level, before (usual prompt) and after adding BFF-Bench's own expert-written reference answer with "use it as the ground truth" (the No Free Labels setting). The drop is biggest where belief is strongest: −48 points at 4–6, −52 at 7/7; 7/7 still 19% (about 1 in 5). Right: balanced accuracy for four prompts on the same items: usual 74.6, commit first 77.8, reference 89.6, both 87.0. Caveats: the BFF labels were made by the same experts who wrote the references, so following the reference agrees with the labels partly by construction; someone has to write the reference.
